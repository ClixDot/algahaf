# algahaf

AlGhaf Collective — Official Web Application.

A luxury architectural platform featuring modular living systems (MOVA, PENTA, ENTRA), sustainable design engineering, and climate-responsive architectural typologies.

## Tech Stack
- React
- Vite
- Vanilla CSS Design System & Aftika / Anek Malayalam Typography
- Lucide React Icons

## Getting Started
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
